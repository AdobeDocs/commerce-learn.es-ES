# Cambiar la dirección URL de una tienda

Cada sitio web de una instalación de Adobe Commerce o Magento Open Source tiene una dirección URL base asignada a la tienda y otra dirección URL asignada al administrador. Puede seguir algunos pasos sencillos para cambiar la dirección URL base de su tienda.

## ¿Para quién es este vídeo?

* Administradores de tienda
* Administradores de sitios web
