# Configuración de Adobe Commerce Services Connector

Commerce Services Connector es una configuración de Adobe que habilita la funcionalidad SaaS. Para utilizar Payment Services para Adobe Commerce y Magento Open Source, conecte la instancia de Commerce mediante las claves de API de producción y de zona protegida, y especifique el espacio de datos en la configuración.

Para ayudarle a configurar Payment Services, vea el vídeo _Configuración del conector de Adobe Commerce Services_.

## ¿Para quién es este vídeo?

* Ingenieros operativos
* Administradores de comercio electrónico y puntos de contacto

## Preguntas frecuentes sobre configuración

El siguiente vídeo trata tareas y problemas comunes de configuración del Conector de servicios de Commerce:

* Corrija las claves públicas o no válidas.
* Gira la clave API de tu tienda.
* Vaya al paso Identificador SaaS de la configuración de Commerce Services Connector.
* Solucione los problemas del botón de zona protegida al incorporar Servicios de pago.
* Commerce Services Connector no se carga en la interfaz de usuario.
