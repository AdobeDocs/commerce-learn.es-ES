# Integraciones de conexión de Adobe Commerce Developer Agent

El código generado necesita un lugar donde ejecutarse y una conexión con la tienda. En esta fase se integra todo (se aloja el código en App Builder, se conecta a la instancia de Adobe Commerce y se vincula un repositorio de GitHub) antes de habilitar la función.

## ¿Para quién es este vídeo?

* Desarrolladores de Commerce
* Arquitectos de soluciones
* Ingenieros back-end

## Contenido de vídeo

* Creación de un proyecto de App Builder y un espacio de trabajo para alojar el código que creó el agente de desarrollo
* Al observar el andamiaje del agente, el proyecto y los elementos de configuración pendientes
* Añadir la credencial de la API de Adobe Commerce as a Cloud Service necesaria en la consola del desarrollador
* Conexión del código a una instancia específica de Adobe Commerce Cloud Service
* Para almacenar y crear una versión del código, vincule un repositorio de GitHub
