# Adobe Commerce Developer Agent: implementar, asociar e instalar

Con todo conectado, la aplicación está lista para la producción. Esta fase implementa el código, lo asocia y lo instala en el administrador de Adobe Commerce para que la nueva función esté habilitada en la tienda.

## ¿Para quién es este vídeo?

* Desarrolladores de Commerce
* Arquitectos de soluciones
* Administradores de Commerce

## Contenido de vídeo

* Solicitud al agente de desarrollo para que se despliegue desde el chat y confirmación de la organización, el proyecto y el espacio de trabajo exactos
* Una fase de validación previa a la implementación y, a continuación, transmitir la generación y la salida de publicación a medida que se implementa el código
* Asociación de la aplicación implementada a una tienda específica desde la pantalla de administración de aplicaciones de Commerce
* Revisión de la tarjeta de la aplicación: nombre, versión y las funcionalidades que agrega (un webhook)
* Instalación de la aplicación para activar la función y confirmación de su instalación correcta
