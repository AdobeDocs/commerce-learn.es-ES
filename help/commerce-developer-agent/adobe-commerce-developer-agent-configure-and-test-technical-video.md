# Configuración y prueba de Adobe Commerce Developer Agent

Una vez que la aplicación está instalada, sus límites y mensajes se convierten en ajustes empresariales que cualquiera puede ajustar, no se requiere código. Esta fase configura el límite de cantidad del carro de compras y lo prueba en directo en la tienda para confirmar que la regla funciona.

## ¿Para quién es este vídeo?

* Desarrolladores de Commerce
* Administradores de Commerce
* Comerciantes

## Contenido de vídeo

* Revisión de la configuración empresarial expuesta por el agente: la cantidad máxima del carro de compras y el mensaje dirigido al comprador
* Reducción del valor predeterminado de las unidades máximas del carro de compras por SKU a un valor inferior y ahorro, sin cambios en el código
* Añadir productos a la tienda y superar el límite configurado
* Confirmación del bloque y el mensaje de error exacto, aplicados en directo sin una nueva implementación
