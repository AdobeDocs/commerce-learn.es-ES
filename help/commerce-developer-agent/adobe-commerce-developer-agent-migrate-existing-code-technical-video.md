# Adobe Commerce Developer Agent migrar código existente

No todos los proyectos comienzan a partir de una configuración vacía. En este ejemplo se migra una extensión existente a App Builder, pasando de PaaS Platform a Adobe Commerce as a Cloud Service, mediante la herramienta de evaluación de migración para alimentar al agente de desarrollo.

## ¿Para quién es este vídeo?

* Desarrolladores de Commerce
* Arquitectos de soluciones
* Ingenieros back-end

## Contenido de vídeo

* Análisis de una instancia de Commerce existente con la herramienta de evaluación de la migración: clasificaciones de complejidad, impacto por módulo, señales de riesgo y una recomendación de reconstrucción, refactorización, sustitución o eliminación
* Revisión de la evaluación de un módulo de alto impacto, incluidos sus enlaces, archivos y un resumen de propósito en lenguaje sencillo que funciona como mensaje listo para su uso
* Envío de la evaluación directamente al agente de desarrollo sin copia manual
* Para centrar la primera pasada en capacidades específicas, responda a las preguntas de ámbito del agente
* Generación de un modelo de webhooks sincrónicos que reemplacen la lógica heredada más riesgosa, con un diagrama de arquitectura
* Crear la implementación con un archivo de prueba coincidente escrito junto con cada controlador
