# Conclusión de Adobe Commerce Developer Agent

Este breve resumen resume el recorrido de Adobe Commerce Developer Agent: desde un requisito en inglés sencillo o una extensión heredada hasta una función de tienda en funcionamiento y probada, sin codificación manual.

## ¿Para quién es este vídeo?

* Desarrolladores de Commerce
* Arquitectos de soluciones
* Líderes en desarrollo

## Contenido de vídeo

* Un resumen del flujo de extremo a extremo, desde los requisitos escritos hasta una función de tienda implementada y probada
* Cómo se aplica el mismo flujo de trabajo si comienza con una descripción en lenguaje sencillo o migra una extensión existente
