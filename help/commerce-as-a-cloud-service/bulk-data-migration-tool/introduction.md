# Introducción a la herramienta de migración masiva de datos

Prepare Docker y acceda a la herramienta de migración masiva de datos para migrar datos de Adobe Commerce a [!DNL Adobe Commerce as a Cloud Service] ([!DNL ACCS]).

## ¿Para quién es este vídeo?

* Arquitecto de soluciones
* Ingeniero de DevOps
* Desarrollador back-end

## Contenido de vídeo

* Conozca las funcionalidades y limitaciones de la herramienta de migración masiva de datos.
* Confirme que Docker está instalado y que el motor de Docker se está ejecutando antes de iniciar.
* Extraiga el paquete de herramientas y establezca los permisos de carpeta correctos.
* Revise el archivo `.env.example` configurado en los siguientes vídeos de esta serie.
